## ⚡ Who I Am

Computer Science and Artificial Intelligence Engineer, MSc in AI, working at the intersection of **systems programming, high-performance computing, and machine learning infrastructure**. I care less about calling a framework's `.fit()` and more about what happens underneath: how memory is laid out, how work gets scheduled across cores, why a kernel is or isn't saturating the hardware. My research-oriented approach treats AI as a systems problem first — interpretability and performance over black-box convenience.

As a long-time Arch Linux user, I default to understanding the machine from the ground up: the kernel, the compiler, the allocator, the instruction set — not just the library on top. That philosophy shapes every project below: they exist to answer *why does this work the way it does*, not just to ship a demo.
